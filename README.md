# Thesis
This repository contains the code for the simulations supporting the results, and creating the corresponding figures from the Thesis "Memory constraints in quantum certification and learning - Sound Certification via Quantum System Quizzing" by Jan Nöller at TU Darmstadt


prefixtree.py:    Library for qutrit-MUB notebook
qutrit_MUB:       Implements the method developed in https://link.springer.com/chapter/10.1007/978-3-642-15488-1_7

Hypergraph: Notebook for numerically computating the Geometric measure of entanglement in several symmetric hypergraph states

QSQ_Robustness_SDP: Numerical solution of the SDP to produce the data for the figures in the discussion of Chapter 3.6
