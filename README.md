# Thesis
This repository contains the code for the simulations supporting the results, and creating the corresponding figures from the Thesis "Memory constraints in quantum certification and learning - Sound Certification via Quantum System Quizzing" by Jan Nöller at TU Darmstadt



qutrit_MUB:           Python notebook implementing the algorithm developed in https://link.springer.com/chapter/10.1007/978-3-642-15488-1_7 to check solvability of MUB_d

prefixtree.py:        Library for qutrit-MUB notebook

Hypergraph:           Mathematica notebook for numerically computating the Geometric measure of entanglement in several symmetric hypergraph states

QSQ_Robustness_SDP:   Python notebook for solving the SDP to produce the data for the figures in the discussion of the QSQ-scaling in Chapter 3.6
